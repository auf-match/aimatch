# АУФ Match

Внутренний инструмент рекрутингового агентства АУФ для найма дизайнеров.
AI разбирает резюме и портфолио кандидатов, структурирует данные и матчит их
с вакансиями — вместо ручного просмотра базы на 2000+ человек дизайн-лид
получает рабочий пул из 30–60 релевантных.

## Стек

- **Next.js 15** (App Router) — и фронтенд, и API-роуты в одном приложении
- **PostgreSQL** (Neon, облако) + **Prisma** — данные
- **Google Gemini** — весь AI: парсинг резюме, анализ портфолио, матчинг, скоринг, эмбеддинги
- **Playwright** — скрейпинг портфолио (Behance, Notion, личные сайты), Figma — через REST API

## Быстрый старт

```bash
npm install
npx prisma generate
npx playwright install chromium   # нужен для скрейпинга портфолио
cp .env.example .env              # заполнить значения (см. ниже)
npm run dev                       # http://localhost:3000
```

### Переменные окружения

Минимум для локального запуска — `DATABASE_URL` и `GEMINI_API_KEY`.
`BASIC_AUTH_*` в dev можно оставить пустыми: middleware пропустит без пароля.
Полный список с комментариями — в [`.env.example`](.env.example).

## ⚠️ Команды, опасные для общей базы

```bash
npm run seed         # УДАЛЯЕТ ВСЕ данные (deleteMany по всем таблицам) и заливает тестовые
npm run db:migrate   # prisma migrate dev — при расхождении схем может предложить reset
```

Для применения миграций на рабочей базе используйте безопасную команду:

```bash
npx prisma migrate deploy   # накатывает только новые миграции, данные не трогает
```

## Как работает анализ кандидата

1. **Скрейпинг** портфолио: главная + до 5 кейсов, каждый прокручивается целиком со скриншотами
2. **Парсинг** резюме/текста портфолио через Gemini → роль, грейд, навыки, домены
3. **Классификация** направления: продуктовый или коммуникационный дизайнер
4. **Анализ портфолио**: скриншоты (до 150, с подписями «кейс N, экран M из K») → 7 оценок 0–100 + разбор кейсов
5. **Эмбеддинг** профиля для семантического поиска «найди похожих»

Ошибки обрабатываются по стадиям: если упал анализ портфолио, результат парсинга
резюме сохраняется, статус остаётся `PARSED`, оценки добираются отдельной кнопкой.

## Деплой

Приложение разворачивается из `Dockerfile` на любом контейнерном хостинге.
Пошаговая инструкция — в [`DEPLOY.md`](DEPLOY.md).

Диагностика окружения на развёрнутом сервере: `GET /api/health` — показывает,
видит ли контейнер переменные и доходит ли до базы (под Basic Auth, секреты не раскрывает).
