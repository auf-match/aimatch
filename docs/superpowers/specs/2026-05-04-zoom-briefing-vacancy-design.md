# Создание вакансии из записи Zoom-брифинга

## Цель
Рекрутер загружает .m4a с брифинга → AI расшифровывает и структурирует в портрет вакансии → форма создания вакансии открывается с предзаполненными полями, подсветкой пропусков и сомнительных мест → рекрутер дозаполняет и сохраняет.

## Поток
1. `/vacancies/new` — выбор «Загрузить запись брифинга (.m4a)», файл ≤ 200 MB / ≤ 2 ч.
2. `POST /api/vacancies/parse-audio`:
   - Upload в Gemini Files API
   - Pass 1 (`briefing-transcribe`): аудио → транскрипт со спикерами (`[Спикер 1]`, ...)
   - Pass 2 (`briefing-parse`): транскрипт → `{ summary, fields: { name: { value, confidence } } }`
   - Удаление файла из Gemini Files
3. Frontend получает результат, заполняет существующую форму, подсвечивает:
   - `confidence: "low"` → жёлтая рамка («AI не уверен — проверь»)
   - `value: null` → серая dashed рамка («AI не нашёл, заполни»)
4. При сохранении — `briefingTranscript` + `briefingSummary` записываются в `Vacancy`.

## Схема БД
```prisma
model Vacancy {
  ...
  briefingTranscript  String?   // полный транскрипт со встречи
  briefingSummary     String?   // 1-2 абзаца саммари
}
```

## API
`POST /api/vacancies/parse-audio` (multipart, поле `file`, `maxDuration: 300`)

Response:
```ts
{
  summary: string,
  transcript: string,
  fields: {
    [k: string]: { value: T | null, confidence: "high" | "low" | null }
  }
}
```

## Промпты
- `prompts/briefing-transcribe.ts` — буквальная транскрипция с метками говорящих, без пересказа
- `prompts/briefing-parse.ts` — парсит транскрипт в `{ summary, fields[*].confidence }`, не выдумывает

## Технические решения
- Gemini Files API для аудио (до 2 ГБ, 9.5 ч — с запасом)
- Оба прохода через `callGemini` → автофолбэк на `gemini-2.5-flash-lite` при квоте
- Транскрипция и парсинг разнесены — чтобы каждая задача была проще и можно было «переанализировать» без перетранскрипции (фолоу-ап фича)

## YAGNI (не делаем сейчас)
- Прогресс-бар реального времени — обычный спиннер
- Кнопка «переанализировать» — добавим если выяснится что нужно
- ffmpeg для извлечения аудио из mp4 — пока только m4a/mp3/aac
- UI отображения транскрипта на готовой вакансии — сохраняем, не показываем

## Edge cases
| Кейс | Поведение |
|---|---|
| Файл > 200 MB или длительность > 2 ч | 400 с понятной ошибкой |
| Gemini квоты исчерпаны на обе модели | 502, существующее сообщение |
| Транскрипт пустой | 422 «не удалось распознать речь» |
| Шаг 2 упал, транскрипт есть | Вернуть `fields: {}` + transcript + summary, форма откроется пустой |
| Не m4a/mp3/aac | 400 валидация |
